# Analytics Portfolio

Portfolio website for Martina Carrazzoni.

## Publishing
Upload the **contents** of this folder to the root of the `analytics-portfolio` repository. Then enable GitHub Pages under Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Notes
- Power BI `.pbix` files must be downloaded and opened in Power BI Desktop.
- The R script retains its original local CSV path. Download the Coffee Shop Sales dataset from Maven Analytics and update the CSV path before running.
- All project files in this repository will be public after upload. Check for confidential or personal data before uploading.
